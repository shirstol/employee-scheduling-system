# Employee Scheduling System

## Overview
A Java-based system for assigning employee shifts based on availability constraints.  
The system allows employees to submit their availability and enables managers to create schedules accordingly.

## Features
- Employee availability submission
- Manager-controlled shift assignment
- Role-based functionality (employee vs manager)
- Basic validation of constraints and scheduling conflicts

## Technologies
- Java
- Object-Oriented Programming (OOP)

## Contribution
Developed as part of a team project. Contributed to implementing scheduling logic and role-based functionality.

## How to Run
1. Open the project in IntelliJ or any Java IDE  
2. Run the main class to start the program
